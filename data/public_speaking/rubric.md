# Public speaking script - Marking rubric

Task: write a short speech script (about 1 minute, 80-150 words) to persuade your class about something you care about.
There are 4 criteria, each worth 0-2 points. Total: 8 points.

## Public speaking script

### Opening hook (2 points)
- 2: starts with something that grabs attention, such as a question, a surprising fact or a short story
- 1: has an opening, but it is plain (for example "Today I will talk about...")
- 0: no clear opening; jumps straight into details

### Clear main message (2 points)
- 2: the main idea or opinion is stated clearly near the start and the whole script sticks to it
- 1: the main idea is there but is unclear, or the script wanders off it
- 0: no clear main idea

### Reasons and examples (2 points)
- 2: gives at least two reasons, each backed by an example, fact or personal experience
- 1: gives only one reason, or reasons without any examples
- 0: no reasons given

### Strong ending (2 points)
- 2: ends with a summary of the message and a call to action (asks the audience to do or think something)
- 1: has an ending, but it only summarises or just stops with "thank you"
- 0: no ending; the script just stops
